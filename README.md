# Homes Contact Converter

The Team's tool for turning contact exports (Remine, iPhone, Google,
Outlook, Lofty, LinkedIn...) into a file the Homes platform can import.

**Use it here:** https://psventresca.github.io/homes-contact-converter/

Files are converted inside your browser -- nothing you choose is uploaded.
This repository only holds the published page; it's updated with
`publish.py` from the source project.
