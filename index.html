    Upload the import file to Homes exactly as it downloaded.

    Don't open it in Excel and save it first. Excel quietly removes the leading zero from ZIP codes like 02140 and changes dates and phone numbers. Opening the other files in Excel just to read them is fine.

    Importing into Homes

    1. Open the Homes contact import page.
    2. Choose CSV, then pick the file ending in "Homes import.csv" from your Downloads folder.
    3. Afterward, open the "needs a quick look" file (if you got one). It lists those contacts with the reason, so you can fix them in Homes.
